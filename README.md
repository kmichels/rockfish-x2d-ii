# Rockfish X2D II

Rockfish X2D II is a camera profile for Adobe Lightroom Classic. It brings
Hasselblad X2D II raw files close to how Phocus renders them.

The profile is now distributed through my blog, free for subscribers:
https://blog.tonalphoto.com/rockfish-x2d-ii/
